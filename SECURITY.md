# Reporting security issues

Do not report undisclosed vulnerabilities in public issues. Contact the project maintainers privately with a concise description, affected version or commit, reproduction steps, impact, and a suggested mitigation if available.

Never attach credentials, refresh tokens, private keys, ROMs, saves, packet captures containing personal data, or server databases. Redact logs before sharing. The client must not log access tokens, refresh tokens, game tickets, passwords, or raw WebSocket payloads.
